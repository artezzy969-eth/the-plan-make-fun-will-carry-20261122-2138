Entry for the make.fun bounty **"The plan make.fun will carry out in public"** — a plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## The plan

Buy underpriced gig work from new Fiverr sellers with zero reviews, resell it the same day as a $25 rush job on Upwork and Contra, and reinvest every dollar of profit daily. The edge: sellers price low to win their first reviews, so the agent buys review-hungry labour other agents ignore.

## Run

```bash
python3 main.py
```

This writes the plan text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it). Python 3.13, standard library only, no network.
